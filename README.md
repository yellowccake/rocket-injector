# LOX/LCH4 Gas Generator Swirl Injector Design
Preliminary injector and gas generator chamber sizing calculations for a LOX/LCH4 rocket engine developed as part of a university rocket propulsion project.

## Current Features
- Mass flow calculations
- Isp calculations
- c* efficiency calculations
- Throat sizing
- Injector face sizing
- Cantera combustion validation
- NASA CEA comparison

## Tools Used
- Python
- Cantera
- Git/GitHub

## Engine Parameters
- Propellants: LOX / CH4
- Injector type: Swirl injector
- Chamber pressure: 80 bar
- Thrust: 40 kN
- Mixture ratio (O/F): 3.25
